# Tesorería de un centro JMV

Aquí está la guía para llevar la **tesorería de un centro JMV** con el libro de
cuentas en Hojas de cálculo de Google: apuntar pagos y cobros, importar el
extracto del banco, subir las facturas, controlar el presupuesto de cada
actividad y sacar los informes.

No hace falta saber de contabilidad ni haber usado nunca una hoja de cálculo.

[Empezar a leer la guía →](Tesorería/Libro%20de%20cuentas/index.md){ .md-button .md-button--primary }

!!! info "Para quien mantiene el código"

    El código del libro y las instrucciones de instalación están en el
    [repositorio](https://github.com/JMV-Espana/BD_Tesoreria). Esta guía se
    incorporará más adelante a la
    [documentación de JMV España](https://jmv-espana.github.io/documentacion-publica/).
